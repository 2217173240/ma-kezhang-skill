# 示例四：无法回避的终极追问（S4）

## 输入情境

- 提问方：客户方高层，在会议现场，已经听过一轮 S1 式的回答，明显不满意
- 已知事实：内部最新节点是"两周内具备上线条件"，但该节点尚未经审批，不能对外承诺
- 客户原话："你别跟我说这些过程了。你就告诉我，能不能按期交付？是，还是不是？"

## 分类

S4 无法回避的终极追问。**承认问题重要 + 需要核实准确口径 + 不当场拍板 + 承诺书面答复 + 给出你个人可控的下一步。**

## 输出

**口头版（现场用，3 句，语速放慢）**

> 您这个问题非常关键，我必须给您一个准确的答复，不能随口应您。按期交付是我们共同的目标，目前团队确实在按计划推进。但最终日期我需要根据最新节点核实后，今天下班前形成书面说明给您，绝不耽误您排期。

**正式版（会后书面）**

> 尊敬的 X 总：
>
> 关于您会上提出的交付节点问题，我们完全理解您需要明确答复。经核实，项目主体工作已按既定安排推进，当前处于上线前验证阶段。为对您负责，避免提供未经审批的时间信息造成双方排期口径不一致，具体节点我们将在完成内部确认后，于本周内以书面形式正式回复贵方，并由项目经理专人对接后续排期。
>
> 感谢您对项目进展的关注与督促。

## 三个动作缺一不可

1. **承认问题关键**——跳过这步，后面全部会被听成敷衍。
2. **拒绝当场拍板，但给出拒绝的理由**——理由是"为了不给您错的信息"，不是"我不管这事"。
3. **给出你自己可控的下一步**——"今天下班前书面说明"承诺的是**你的动作**，不是业务结果。这是唯一允许出现具体时间的情形。

## 用到的规则

- 三转：转渠道（口头 → 书面）、转程序（未审批节点不能对外）
- 四不：不具体（不给日期）、不承诺（不说"能按期"）、不否定（不说"不能"）、不归因
- 一留：书面答复 + 专人对接

## 自检

| # | 检查 | 结果 |
|---|---|---|
| 1 | 有无具体业务数字/日期 | 无业务日期；"今天下班前"是**我方动作**的时限，允许 ✅ |
| 2 | 有无"一定/肯定" | 无 ✅ |
| 3 | 有无承认或否认 | 未答"是或不是"，用"共同目标 + 正在推进"承接 ✅ |
| 4 | 有无归因 | 无 ✅ |
| 5 | 有无渠道和下一步 | 有：书面 + 专人对接 + 我方时限 ✅ |
| 6 | 对方能否安全转述 | 可以；他向上汇报"对方承诺今天下班前书面答复"，你确实做得到 ✅ |
| 7 | 可解析度 | 未交付任何立场或定性；读三遍只能得出"对方会书面答复" ✅ |

## 附：当问法本身是陷阱

S4 里最危险的不是"能不能按期"这种逼承诺的问法，而是**问题里已经预埋了定性**的问法。这时无论答"是"还是"不是"，你都替某个主体签了字。

**输入**：对方在会议上追问——"我们了解到，你们有几家供应商的资质文件是后补的，这个不合规吧？"（事实基础：确实存在补件，但属于制度允许的补正程序；是否"不合规"的定性权不在你手上。）

**错误应对（两个方向都错）**

> ✗ "是的，这块确实不太规范，我们后续整改。"

等于当场承认不合规，把"整改"责任也一并接下——事后无论补件是否合规，这句话都是呈堂证供。

> ✗ "没有的事，我们全部合规。"

等于替全部流程背书。只要有一份文件确实晚于节点，这句话就变成不实陈述。

**正确应对（把问题从"定性"拉回"事实 + 程序"）**

> 您提到的这个情况我需要核实准确口径，不便凭单一环节下结论。供应商资质文件的管理，我们是按既定制度和补正程序执行的，相关记录完整可查。是否属于您说的那种情形，以及如何认定，以正式核查结论和书面材料为准。会后我把对应的制度条款和文件清单整理给您，由专人对接。

**为什么这样答是安全的**

- 没有承认"不合规"（定性权不在你），也没有否认"存在补件"（那是可查事实）。
- 把"合规与否"交回制度和正式结论，而不是由你现场认定。
- 交付了姿态和动作（核实、整理清单、专人对接），对方不会觉得被敷衍。
- 第 7 问过：这段话读三遍，挖不出"他承认了……"或"他否认了……"。

## 常见失败版本

| 失败输出 | 为什么失败 |
|---|---|
| "这个我无可奉告。" | 硬刚，激化对抗，且暗示有隐情 |
| "应该能按期吧。" | 模糊承诺，事后来不及，第 2 问不过 |
| "您别问了，我真不清楚。" | 复刻马科长当年"别讲了"，在今天不体面也没有渠道兜底 |
| "肯定能，您放心。" | 超出授权承诺业务结果，第 2、5 问不过，风险最高 |
| "主要看你们那边确认快不快。" | 归因客户，第 4 问不过 |
