# 示例二：敏感决策 / 责任类追问（S2）

## 输入情境

- 提问方：客户方审计/纪检口的工作人员（或客户方的内部质疑者）
- 已知事实：供应商选择走了公开比选流程，有评审记录；最终审批是集体决策会议；具体会议纪要未对外公开
- 无授权：不便披露评审打分和参会人姓名
- 客户原话："这个供应商是谁定的？为什么选他们？中间有没有打招呼？"

## 分类

S2 敏感决策 / 责任类。三个问题层层递进：决策人 → 决策依据 → 合规性。**把个人决策转成组织程序，把"有没有"转成"以记录为准"。**

## 输出

**正式版**

> 您关注的核心是决策依据和合规性，这点非常重要。该供应商的确定严格遵循公司采购管理制度，经过了需求论证、资质审查、公开比选和集体评审等既定程序，不属于任何个人可以决定的事项，全过程留痕可查。具体的评审记录与决策文件，可以通过正式渠道依规调阅。我们当前的工作重点是按既定方案推进落地，确保交付质量。如后续需要配合核查，我们会按流程提供材料。

**口头版（3 句）**

> 这是走的公开比选加集体评审，有评审记录，不是哪个人能定的。具体记录您走正式渠道可以调阅。我们这边全力配合。

## 关键动作

第 3 句"如后续需要配合核查，我们会按流程提供材料"是**必要的**——对审计/纪检口，纯缓冲会被读成心虚。配合 + 依规，比任何形容词都有用。

## 用到的规则

- 三转：转程序（谁定的 → 集体评审程序）、转渠道（记录 → 依规调阅）
- 四不：不具体（不给姓名、分数）、不归因（不提任何个人）、不否定（不说"绝无打招呼"）
- 一留：正式调阅渠道 + 配合承诺

## 自检

| # | 检查 | 结果 |
|---|---|---|
| 1 | 有无具体数字/日期/金额/人名 | 无 ✅ |
| 2 | 有无"一定/肯定" | 无 ✅ |
| 3 | 有无承认或否认 | **不问**"有没有打招呼"，只答程序 —— 这是本场景的核心 ✅ |
| 4 | 有无归因 | 无个人、无部门 ✅ |
| 5 | 有无渠道和下一步 | 有：依规调阅 + 配合核查 ✅ |
| 6 | 对方能否安全转述 | 可以，且这段在审计场合经得起复述 ✅ |

## 注意

**不要**说"绝对没有打招呼""绝对合规"——绝对化表述一旦被查出任何瑕疵，缓冲就变成不实陈述。也不要暗示"是上面定的"，那是归因，会把自己和上级一起装进去。

如果对方已经掌握具体违规线索并明确列举，**立即停止缓冲**，转法务与合规流程，如实提供材料。
