# 替换词表

把"直白但不该说"的词，换成"准确但不留把柄"的词。左侧直接说会带来风险，右侧是同等长度下更安全的表达。

| 少说 | 多说 |
|---|---|
| 不知道 | 需要核实准确口径 |
| 没做 | 正在按计划推进 |
| 延期 | 动态优化节点 |
| 有问题 | 面临阶段性挑战 |
| 领导决定的 | 经过既定程序研究 |
| 肯定行 | 在条件具备的情况下全力推进 |
| 不是我们的问题 | 需要进一步厘清责任边界 |
| 没钱 | 资金安排正在统筹 |
| 被通报了 | 相关情况以正式通报为准 |
| 我保证 | 我们会尽最大努力推进 |
| 不可能 | 目前不具备可行性，需进一步论证 |
| 已经失败了 | 阶段性结果与预期存在差距，正在复盘 |
| 客户不同意 | 双方仍在充分沟通，尚未形成一致意见 |
| 我们错了 | 相关情况我们已关注，正在按流程核查 |
| 下周一定给 | 具体时间以确认后的正式通知为准 |
| 成本超了 | 成本情况以正式财务口径为准 |
| 没人管 | 已明确责任部门，正在推进落实 |

## 使用注意

1. **替换不是撒谎**。右侧每一句都必须在事实上站得住；如果连"正在推进"都不成立，就不要用这张表，直接走"需要核实"。
2. **不要堆叠**。一段话里塞满替换词会显得空洞、被识别为套话。一次回复用 2–3 个即可。
3. **保留可验证的锚点**。至少留一个真实、可查的东西（已完成的环节、正式材料名称、会议时间、责任部门），否则整段话没有信息量、也没有可信度。
4. **正式材料优先**。凡是能指向周报、月报、会议纪要、正式函件的，都指过去，这比形容词有用。
